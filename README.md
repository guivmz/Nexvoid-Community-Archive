<div align="center">⌁ ARCHIVE OVERVIEW

A PROJECT LEFT BEHIND. A COMMUNITY THAT DIDN'T FORGET.

</div>This repository is dedicated to preserving the recovered source code of an abandoned Flee the Facility project for Roblox.

Following the apparent discontinuation of the original project, its codebase was left without active development or maintenance.

The recovered scripts have been deobfuscated and organized to make their internal structure accessible to the community.

Our intention is simple: preserve the original work and provide developers with an opportunity to understand, maintain, repair, and continue improving it.
